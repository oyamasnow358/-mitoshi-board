# みとおし ボード（MieeL）

「いつ おわる？ つぎは なに？」を わかりやすく する、みとおし・きりかえ しえんの アプリです（特別支援教育向け・iPad / iPhone）。

## できること
- **しゃしんで きょうの よてい**：カメラで とる・しゃしんを えらぶ（まとめて も）・えもじカード（がっこう／いえ／おでかけ／やすむ・おたのしみ）。よていは いくつでも つくれて「きょうに する」で つかう
- **のこりじかんを いろと りょうで**：えんが へる／バーが へる／ブロックが きえる。みどり → きいろ → あか。「あと 7ふん」「🕒 10:30 に おわり」、もうすぐ おしまいの しらせ、おしまいの じかんの がめん（＋1ぷん も）
- **「あと 1かい」**：かいすうを いれると ○ を タッチで けして いき、のこり 1かいで「あと 1かい！」
- **「おわったら きゅうけい」**：つぎの カードを いつも みせ、つぎが きゅうけい・おたのしみ なら「おわったら きゅうけい！」。💬 ことばカード（あと 1かい・つぎで おしまい など）を おおきく みせて よみあげ
- **よていの へんこう**：とちゅうで かえると、こどもの がめんに「まえの よてい → あたらしい よてい」（なし・あたらしい・じゅんばん・じかん）と「○○ は なし → かわりに △△」を おおきく しらせる。かわった カードには しるし
- **まちがえて すすんだ とき**：「↩ ひとつ もどる」や、うえの よていを タッチして その よていへ（たしかめ つき）。もどった ときの タイマーは つづきから
- **まず → つぎ**：2まいだけで きりかえる かんたん モード（タイマーつき）
- こどもの がめんの 🏠 は ながおし（うっかり もどらない）、せんせいの へんしゅうは 1びょう ながおし
- **A4 プリント**：よていひょう（しゃしんつき・チェック らん）／きりとり カード／まず→つぎ ボード（みほんと おなじ ものを いんさつ）

## こじんじょうほう
しゃしんと よていは **この たんまつ（ブラウザ）の なかだけ**（IndexedDB・localStorage）に ほぞん し、インターネットには おくりません。オフラインでも つかえます。ほかの たんまつへの いどうや バックアップは「ファイルに かきだす／よみこむ」で おこないます。
